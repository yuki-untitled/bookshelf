# Bookshelf

自分専用の本棚Webサイト。蔵書と読書記録を一箇所に集約し、書店でバーコードを読み取って、同じ本を持っているかをその場で確認できる。

> 現在は仕様策定の段階で、実装はまだない。仕様は `develop` ブランチの [docs/spec/](docs/spec/) にある。

## 目的

所有している本と読んだ本が、紙のメモ・記憶・購入履歴に散らばっている。これを1つのサイトに集約し、「何を持っているか」「何を読んだか」を確認できるようにする。主な利用場面は、書店や古書店での購入前の重複確認（二重購入の防止）。

## 主な機能

| 機能 | 内容 | 仕様 |
|---|---|---|
| 本の管理 | 本の登録・閲覧・編集・削除。表紙中心のグリッド一覧で、絞り込み・検索・並べ替えができる。所有の有無は読書ステータスと独立して持つ。 | [book-management.md](docs/spec/book-management.md) |
| 読書記録 | ステータス（読みたい・読書中・読了・積読）、読了日、星1〜5の評価、レビュー、タグを本ごとに記録する。 | [reading-record.md](docs/spec/reading-record.md) |
| ISBN・バーコード取得 | ISBN入力またはカメラのバーコード読み取りで書誌情報を取得し、登録フォームに入力する。所有確認では、読み取った本が「所有しています」「登録済み・未所有」「未登録」のどれかを、登録せずに表示する。 | [isbn-lookup.md](docs/spec/isbn-lookup.md) |
| 画面デザイン | 表紙を主役にしたダークテーマ。アクセントカラーはアンバー（#F5A524）。スマートフォンを基準画面（幅375px）とし、PC幅（1280px）にも対応する。ホーム画面に追加してアプリのように起動できる。 | [design.md](docs/spec/design.md) |

## 前提・制約

- 利用者は自分1人。アプリ自体はログイン機能・複数ユーザー・他人への公開機能を持たない。
- 自宅サーバー（NUC）で稼働し、データも自宅サーバーに保存する。インターネット経由でスマートフォンとPCから使う。
- 本人以外のアクセスは、アプリの外側（公開経路の入口）で遮断する。
- バックアップの取得と復元ができる。
- ホーム画面からの起動は、オフライン動作を含まない。

## 開発方針

仕様駆動開発（SDD）で進める。コードを書く前に仕様を読み、コードを変えたら仕様も同時に更新する。仕様には Why と What を書き、実装方法（How）は書かない。
