# 画面デザイン — 表紙を主役にしたダークテーマの本棚

## Issue
#未起票

## 目的（Why）
自分の本棚を開くこと自体が楽しい体験にしたい。表紙を並べて眺められ、暗い部屋でも目が疲れず、スマホでもPCでも同じ世界観で使えるようにする。参照元は、表紙を並べた本棚表示で読書記録を付けられるアプリ「ビブリア」。

## 実現内容（What）
- **テーマ**: ダークテーマのみを提供する。ライトテーマへの切り替えは持たない。
- **配色**: 背景は黒に近い暗色、文字は明るい無彩色、アクセントカラーは1色のみ。アクセントカラーは、ボタン・選択中の項目・星評価に限って使う。
- **本棚（一覧）**:
  - 表紙画像を主役としたグリッドで表示する。1冊あたりの表示は表紙画像のみとし、タイトル・著者は表紙の下に小さく添える。
  - 表紙画像は縦横比 2:3 で統一して表示する。
  - 表紙画像が無い本は、タイトルを表紙の位置に載せたプレースホルダを表示する。
  - 読書ステータスは、表紙の隅のバッジで示す。ステータスごとにバッジの表示を変える。
  - 画面幅に応じて列数が変わる（幅375pxで3列、幅1280pxで6列以上）。
- **詳細画面**: 大きな表紙を最上部に置き、その下にタイトル・著者・ステータス・評価・レビュー・タグを表示する。PC幅では表紙を左、情報を右に並べる。
- **登録画面**: ISBN入力欄とバーコード読み取りボタンを最上部に置く。読み取りボタンを押すと、カメラ映像が全画面で表示され、読み取り枠が示される。
- **操作**: スマートフォンでは主要操作（所有確認・登録・絞り込み・検索）を画面下部のナビゲーションに置き、片手の親指で届く位置にする。所有確認（バーコード読み取り）は、下部ナビゲーションの中央に目立つボタンとして置く。
- **所有確認の結果表示**: 全画面のカメラ映像の下部に結果を重ねて表示し、「所有しています」「登録済み・未所有」「未登録」を文字と色の両方で区別する。
- **ホーム画面への追加**: スマートフォンのホーム画面にアイコンを追加でき、そのアイコンから起動すると、ブラウザのアドレスバーなしの全画面で表示される。アプリ名は「Bookshelf」とし、アイコンと起動直後の背景はダークテーマに合わせる。
- **動き**: 画面遷移と本の追加時にアニメーションを入れる。OSの「視差効果を減らす」設定が有効な場合は、アニメーションを表示しない。

## 受入基準
1. **ダークのみ**: OSの外観設定がライトの場合でも、全画面がダークテーマで表示される。
2. **文字の読みやすさ**: 本文・ボタン・入力欄の文字と背景のコントラスト比がすべて 4.5:1 以上である。
3. **アクセントカラーの用途**: アクセントカラーは、ボタン・選択中の項目・星評価以外では使われていない。
4. **表紙の縦横比**: 本棚上の全表紙が縦横比 2:3 で表示される。縦横比の異なる画像でも、表示が歪まない。
5. **表紙なしの表示**: 表紙画像が無い本は、タイトルが読めるプレースホルダで本棚に表示される。
6. **ステータスバッジ**: 4種類のステータスそれぞれについて、バッジの表示が互いに異なり、色だけに依存せず文字またはアイコンで区別できる。
7. **列数**: 本棚の列数が、幅375pxで3列、幅1280pxで6列以上になる。
8. **タップ領域**: スマートフォン幅で、ボタン・タグ・ナビゲーション項目のタップ領域が縦横とも 44px 以上である。
9. **全画面スキャン**: 読み取りボタンを押すと、カメラ映像が全画面で表示され、閉じるボタンで登録画面に戻れる。
10. **動きの抑制**: OSの「視差効果を減らす」を有効にすると、画面遷移・本の追加のアニメーションが表示されない。
11. **所有確認ボタン**: スマートフォン幅で、本棚画面の下部ナビゲーション中央に所有確認ボタンが表示され、1回のタップでカメラが起動する。
12. **所有確認の結果の区別**: 「所有しています」「登録済み・未所有」「未登録」の3つの結果が、文字の違いで区別できる。
13. **ホーム画面への追加**: iPhone（Safari）と Android（Chrome）の両方で、ホーム画面にアイコンを追加できる。
14. **アプリ表示**: ホーム画面のアイコンから起動すると、アドレスバーが表示されず、アプリ名が「Bookshelf」である。
15. **起動直後の背景**: ホーム画面のアイコンから起動した直後の画面が、白ではなくダークテーマの背景色で表示される。
16. **画面の一貫性**: 本棚・詳細・登録の3画面で、同じ文字サイズ体系・余白体系・ボタン形状が使われている。

## 制約・関連機能
- 表示する本のデータ: [book-management.md](book-management.md)
- ステータス・評価・タグ: [reading-record.md](reading-record.md)
- ISBN入力・バーコード読み取り: [isbn-lookup.md](isbn-lookup.md)
- ホーム画面から起動した場合も、本人以外のアクセスは遮断する（[book-management.md](book-management.md) の受入基準12）。
- ホーム画面への追加に、圏外での利用（オフライン動作）は含めない。
- アクセントカラーはアンバー（#F5A524）とする。
- 背景色は #0E0E10、カードや入力欄など一段持ち上げた面は #1A1A1D とする。
- 文字色は、主を #ECECEE、副を #A0A0A8 とする。いずれも背景に対して 4.5:1 以上のコントラスト比を持つ。
- フォントはシステムフォントを使い、日本語は Noto Sans JP とする。
- 主に使う端末はスマートフォン。設計・確認の基準画面幅は 375px とし、PC 幅（1280px）はその拡張として扱う。
- 最も多い利用場面は、書店でバーコードを読み取って所有を確認すること（[isbn-lookup.md](isbn-lookup.md)）。
