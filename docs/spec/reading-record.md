# 読書記録 — ステータス・評価・レビュー・タグ

## Issue
#未起票

## 目的（Why）
本を持っているだけでなく、「これから読む」「読んだ」「どう感じたか」を残し、後から探し直せるようにする。

## 実現内容（What）
- 各本に読書ステータスを1つ設定できる。ステータスは「読みたい」「読書中」「読了」「積読」の4種類。
  - 「積読」は所有していて未読の本を指す。
  - 新規登録時の初期値は「読みたい」。
- ステータスを「読了」にすると読了日を記録する。初期値は操作した当日で、利用者が変更できる。
- 評価を星1〜5の整数で付けられる。未設定にもできる。
- レビュー（自由記述の感想）を本ごとに1件書ける。
- タグを本ごとに複数付けられる。
  - タグは自由入力で、既存タグは入力中に候補として表示される。
  - タグ名の前後の空白は除去し、同じ名前のタグは1つとして扱う。
  - タグ一覧画面で、タグごとの冊数を確認できる。
- 一覧画面で、ステータスごとの冊数を確認できる。

## 受入基準
1. **初期ステータス**: 本を新規登録すると、ステータスは「読みたい」になっている。
2. **ステータス変更**: 詳細画面でステータスを「読書中」に変更して保存すると、一覧で「読書中」の絞り込みに表示される。
3. **読了日の初期値**: ステータスを「読了」にすると、読了日に当日の日付が入る。
4. **読了日の変更**: 読了日を任意の過去日に変更して保存すると、詳細画面にその日付が表示される。
5. **読了以外の読了日**: ステータスを「読了」から別のステータスに戻すと、読了日は表示されなくなる。
6. **評価の範囲**: 評価は1〜5の整数のみ設定できる。0以下・6以上・小数は設定できない。
7. **評価の解除**: 設定済みの評価を未設定に戻せる。
8. **レビュー保存**: レビューを入力して保存し、詳細画面を開くと改行を含めて同じ内容が表示される。
9. **タグの付与**: タグ「ミステリ」「2026」を付けて保存すると、詳細画面に2件のタグが表示され、タグ「ミステリ」で絞り込むとその本が表示される。
10. **タグの正規化**: 「 ミステリ 」（前後に空白）と「ミステリ」を付けても、タグは1件のみ登録される。
11. **タグ候補**: 登録済みタグ「ミステリ」がある状態で「ミ」を入力すると、候補に「ミステリ」が表示される。
12. **冊数表示**: 読了3冊・読みたい2冊を登録すると、一覧画面に「読了 3」「読みたい 2」と表示される。

## 制約・関連機能
- 本の登録・一覧・絞り込み: [book-management.md](book-management.md)
- 所有は読書ステータスと独立した属性であり、本仕様のステータスには含めない。
- 評価・レビュー・タグはいずれも任意項目。
